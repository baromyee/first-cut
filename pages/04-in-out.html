레슨 04

쓸 구간만 집어 넣기

원본 전체를 타임라인에 끌어다 놓지 않습니다. 왼쪽 위 Source에서 “여기부터 여기까지”를 찍은 뒤, 아래 타임라인에 그 구간만 넣습니다.

목표. 프로젝트 패널 → Source → I/O → 타임라인 재생헤드 → 쉼표(Insert) 순서를 혼자 한 번 끝냅니다.

지금 볼 화면 위치

키보드를 누르기 전에, 네 칸이 어디인지 눈으로 확인하세요. 헷갈리면 창 → 작업 영역 → 편집으로 되돌립니다.

왼쪽 아래

프로젝트

가져온 파일 목록입니다. 클립을 더블클릭하는 곳입니다.

왼쪽 위

Source 소스

원본을 미리 보는 창입니다. I O는 여기가 선택된 상태에서 누릅니다.

오른쪽 위

Program 프로그램

타임라인 결과입니다. 인·아웃을 찍는 곳이 아닙니다.

맨 아래

타임라인

빨간 세로선(재생헤드)이 “여기에 넣을게”를 가리킵니다.

가장 흔한 실수: 오른쪽 Program을 보고 I를 누르는 것입니다. 인·아웃은 왼쪽 위 Source에서 찍습니다. Source 테두리가 밝게 강조되면 그 창이 선택된 것입니다.

1단계. 클립을 Source에 열기

  1. 화면 왼쪽 아래 프로젝트 패널을 클릭합니다. 파일 이름이 보여야 합니다.
  2. 쓸 영상 클립을 한 번이 아니라 두 번 클릭합니다(더블클릭).
  3. 화면 왼쪽 위 Source에 그 영상이 재생되면 성공입니다. 오른쪽 Program이 바뀌지 않아도 됩니다.
  4. Source 화면을 한 번 클릭해 두세요. 다음에 누르는 I O가 여기로 가게 하기 위해서입니다.

더블클릭해도 Source가 안 열리면, 클립을 프로젝트에서 Source 창 안으로 드래그해도 됩니다.

2단계. 쓸 시작(인)과 끝(아웃) 찍기

인(I)은 “여기서부터 쓸게”, 아웃(O)은 “여기까지만 쓸게”입니다. 원본 파일은 잘리지 않고, 가져올 범위만 표시됩니다.

  1. Source 아래쪽 작은 막대(소스 타임라인)를 클릭하거나, 스페이스바로 재생·정지합니다. 한 프레임씩은 ← →입니다.
  2. 쓰고 싶은 첫 장면이 Source에 나온 순간, 키보드 I를 누릅니다. 또는 Source 아래 버튼 중 왼쪽 꺾쇠 { (인 표시)를 마우스로 눌러도 됩니다.
  3. 다시 재생해서 쓰고 싶은 마지막 장면에서 멈춘 뒤 O를 누릅니다. 마우스라면 오른쪽 꺾쇠 } (아웃 표시)입니다.
  4. Source 아래 작은 막대에서 중간만 밝고 양쪽은 어둡게 보이면 성공입니다. 밝힌 부분만 타임라인에 들어갑니다.

잘못 찍었을 때

시작을 다시 맞춘 뒤 I, 끝을 다시 맞춘 뒤 O만 누르면 위치가 바뀝니다. 이전에 찍은 표시는 덮어씌워집니다.

지우고 싶을 때

Source를 우클릭 → 인 앤 아웃 지우기. 또는 메뉴 마커 → 인 앤 아웃 지우기.

I를 눌렀는데 아래 타임라인에 표시가 생기면, 지금 선택된 창이 Source가 아닙니다. Source 화면을 클릭한 다음 다시 I를 누르세요.

3단계. 타임라인에 넣을 자리 정하기

인·아웃은 “무엇을 넣을지”이고, 재생헤드는 “어디에 넣을지”입니다.

  1. 화면 맨 아래 타임라인을 한 번 클릭합니다.
  2. 빨간 세로선(재생헤드)을 마우스로 잡고 끌거나, 눈금 위를 클릭해 옮깁니다. 맨 앞에 넣으려면 타임라인 맨 왼쪽(00:00)으로 가져갑니다.
  3. 이미 클립이 있으면, 새 컷을 넣고 싶은 지점에 빨간 선을 맞춥니다. 클립 사이 틈에 붙이려면 S 스냅을 켜 두는 편이 쉽습니다.

4단계. 넣기 — 처음엔 쉼표만

넣을 때는 Source에 인·아웃이 있는 상태에서 키보드를 누릅니다. 마우스로 프로젝트 클립을 타임라인에 끌어다 놓으면 원본 전체가 들어갈 수 있습니다.

쉼표 ,

Insert 삽입 — 초보 기본

재생헤드 위치를 벌리고 그 사이에 넣습니다. 뒤에 있던 컷은 오른쪽으로 밀립니다. 길이가 늘어납니다. 빈 타임라인에서도 이걸 쓰면 됩니다.

마침표 .

Overwrite 덮어쓰기 — 나중에

이미 있는 컷 위를 지우고 덮습니다. 전체 길이는 그대로입니다. 실수로 좋은 컷이 사라질 수 있습니다.

  1. Source에 밝은 I~O 구간이 있는지 다시 봅니다.
  2. 타임라인 빨간 선이 원하는 자리에 있는지 봅니다.
  3. 키보드 쉼표 , 를 한 번 누릅니다. (한글 입력이 켜져 있어도 보통 동작합니다. 안 되면 영문 키로 바꿉니다.)
  4. 아래 타임라인에 짧은 클립이 생기고, 오른쪽 위 Program에서 그 구간이 보이면 성공입니다.
  5. 마침표 . 는 “이 자리를 바꿔 덮고 싶다”고 확실할 때만 씁니다. 덮인 뒤에는 바로 Program을 재생해 보고, 아니면 Ctrl+Z로 되돌립니다.

입문 컷편집에서는 거의 항상 Insert(,)가 안전합니다. 타임라인에 검은 구멍이나 이상한 클립이 생겼으면 실행 취소 후, Source를 클릭했는지부터 다시 확인하세요.

한 번에 따라 하기

  1. 왼쪽 아래 프로젝트 → 클립 더블클릭 → 왼쪽 위 Source에 영상 확인.
  2. Source 클릭 → 시작 장면에서 I → 끝 장면에서 O → 아래 막대가 일부만 밝은지 확인.
  3. 아래 타임라인 클릭 → 빨간 선을 넣을 자리로 이동.
  4. 쉼표 , → 타임라인에 짧은 클립이 붙었는지 확인 → 스페이스로 Program 재생.

이것을 세 점 편집이라고 합니다. Source에서 두 점(인·아웃), 타임라인에서 한 점(재생헤드). 마우스로 통째로 드래그하는 것보다 앞뒤 군더더기가 덜 들어갑니다.
